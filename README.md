# Portfolio Site

Personal portfolio — Soubhagyashree Das. Static site, no build step.

## Structure
- `index.html` — page markup
- `style.css` — all styling, including the persistent portrait background and responsive rules
- `script.js` — interaction logic (pillar expansion to be extended)
- `assets/` — images. Replace `portrait-placeholder.svg` with a real
  exported piece from your Instagram (PNG/WEBP recommended), then
  update the `background-image` path in `style.css` under
  `.bg-portrait`.

## Local preview
Just open `index.html` in a browser — no server or build tools required.
